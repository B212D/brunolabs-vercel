# BRUNOLABS
1. Mettez ce dossier sur GitHub, puis Netlify > Add new site > Import from Git.
2. Site configuration > Environment variables : ADMIN_PASSWORD = votre mot de passe. Redéployez.
3. Ouvrez le site, "Administration" en bas de page, connectez-vous.
Le mot de passe n'est jamais dans le code : il vit uniquement chez Netlify.
